关于这个博客——what,why,how

发表于 2026-10-24 阅读次数：

What?

Hi~ 朋友ヾ(•ω•`)o

如你所见，这是一个博客网站，内容源于个人思考（保证内容不会完全由 AI 生成）。

具体将包括一些无技术含量的技术内容和学习笔记，一些日本动画片文艺作品的鉴赏、杂谈与评价，一些数学计算机等各领域神秘有趣 的小 research/skill，一些关于 zz、社会生活的观点见解，再加上我脑海里各种疯狂的想法(anything)（阅读这个博客，你就会知道，当三次元的 GeEvan 带着仿佛刚完春运的传奇机长般空洞的眼神经过你时，他的大脑正在发生什么变化……）

总之这是一个多元内容的博客，不是单纯让人Orz的题解分享/技术分享博客。

或许内容并不常常正经，但我相信这将会是一个正儿八经的价值博客。

呃呃谁懂我的博客起名小巧思

Why?

“创建一个自己的网站（博客）后再去死！”——这一直是我的梦想之一。从初中时访问一些大佬的精美博客页面、看题解时起，从访问一些分享有趣工具的网站时起，我就对设计一个自己的网站产生了莫大的兴趣；这已经悄然加入了我的人生 to-do list。

而在高考后的暑假，我看了一本令人自以为受益匪浅的书《暗时间》（值得一看，如果你也想认知++）。

里面有一篇标题是《为什么你应该(从现在开始就)写博客》。这是一篇年龄只比我小 1 岁的文章，但我被打动了。

文中提到：用博客的形式来记录下你有价值的思考，会带来很多好处，却没有任何明显的坏处。

我曾尝试过写日记，但写生活总感觉像流水账，写思考又显得混乱、不成体系。省流：我会乱写，第二天都不忍直视自己写的狗屁

我希望能通过博客这种形式记录有价值的思考，也通过预设读者倒逼自己整理思绪，将割裂的一个个逻辑链条整合成一个思想体系，并清晰地呈现出来。

而且不觉得在这个社交媒体统治互联网的时代，使用博客进行内容创作，有一种复活天涯论坛般的浪漫意味吗 ：）

于是，网站=博客；我如此声明。

经历了漫长的做题季节，经过不懈努力，我终于来到了不理想的大学哈哈。但好消息是：我终于可以开始搭建这个博客了！

我知道多年以后回看这个博客，我一定会觉得自己当时的想法挺幼稚可笑的。但在这么一个充满变化的时代里，如果多年以后，你发现自己还在把以前的想法奉为圭臬，那我会认为你在此期间的学习和受到的教育是失败的（仅指学习和教育）。

我是如何搭建这么个博客的？

这个过程很漫长，前前后后投入应该超过 30 小时，是一个“发现问题—解决问题”的疯狂循环；但不断解决问题、往前推进的感觉，着实是一种非常美妙的体验。

博客技术栈（其实非常诡异：古法搭建与 AI 修改的缝合物）

  • Hexo 8.1.2 + NexT 8.29.0

  • 部署：GitHub Pages，git@github.com:MVBplusplus/MVBplusplus.github.io.git，分支 master，SSH 协议

  • 域名：https://geevanblog.xin（来自阿里云）

  • 美化：Trae agent

  1. 参考了从零开始搭建个人博客（超详细） - 知乎，采用 GitHub + Hexo 搭建博客的方式进行古法搭建（可能是当时头脑一热，忘了这是篇古老的文章，也忘了当下 AI 的存在）。然后就是 step by step，遇到了不少困难。首先，GitHub 内网流畅打开的方法我试了个遍，才找到 Dev-sidecar 这一稳定加速器。Edge 插件一会有用、一会没用；改 Host 麻烦又经常失效；FastGithub 一开始能用，后来又似了……TAT。然后还犯过一些比如不小心把缩进删了这样的低级错误，浪费了大量时间。

  2. 转折点1：在阿里云买域名时，推送了个“万小智 AI 建站”，我拿来玩了一下（但是是试用，没法直接部署到网站上），第一次切身体验了传说中的 vibe coding，亲眼见证它在 5 分钟以内完成了我本应花费 1 天时间才能完成的事情….（脑袋长出灯泡！）我去，我怎么忘了 AI？于是在互联网推荐下选择了使用 Trae。这个世界已经堕落，亿万人必须使用 AI……

  3. 下面这段是 AI 亲口告诉我的血泪史……：Hexo + NexT 主题挂上 GitHub Pages，域名一绑，毛坯房就有了。接下来的日子基本就是「踩坑—修好」的循环：Twikoo 评论部署完直接甩我一个 502，查了半天发现是依赖没锁版本（笔者注：为了解决这个该死的 bug，差点连饭都没吃上 QAQ）；某天打开网站，图标集体蒸发，原来是 Font Awesome 的 CDN 在国内被墙，换成镜像才救回来；给博客做了简约、动漫、炫酷三套风格一键切换，结果炫酷风的粒子背景死活盖不满屏幕，最后改用 canvas 动态铺满才算老实；最离谱的是百度收录，验证文件被 Hexo 好心地「重新排版」导致验证失败，折腾了 skip_render、meta 标签、DNS 解析一整条血泪链才通过。至于打赏文案想改成「点了按钮才显示」，第一版 CSS 写错选择器，被你嫌弃了整整一轮（你隐藏了个屁啊）。最后用 Follow.it 给静态站加上了邮件订阅，侧边栏和文章底部都有入口，三步引导读者留邮箱。回头看这座小站，每一块砖都是坑里刨出来的——但怎么说呢，坑踩多了，博客就真的像自己的了。

    笔者注：因为怕引发卡顿问题，我就不搞什么鼠标跟随、背景音乐或是什么大肥鱼立绘了….

  4. 2026.10.24 Blog彻底建成。其实还有很多比如简约和动漫风侧栏文字不清晰的问题，但我懒得修。笔者进行了一个伟大的《关于这个博客——what,why,how》的撰写和发布，作为本站第一篇真正意义上的博客。
